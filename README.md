# SQL Assignments Collection

This repository contains a collection of SQL scripts and practice assignments covering database concepts, table creations, queries, constraints, joins, and data manipulation.

---

## 📁 Repository Structure

Below are the SQL assignment files included in this project:

- *Assignment_4_5_Homework.sql*: Basic to intermediate SQL practice queries and tasks.
- *Garage_data_homework.sql*: Database operations and queries related to garage management data.
- *Sale_cust_order_homework.sql*: E-commerce / Sales database setup including tables for Customers, Orders, Salespeople, Foreign Keys, and Join queries.
- *Sql_HomeWork_emp_incentive.sql*: Queries related to Employee and Incentive management, salary calculations, and conditional logic.

##  Key Topics Covered

- *DDL & DML Commands*: CREATE TABLE, INSERT INTO, SELECT, UPDATE, DELETE
- *Data Integrity & Constraints*: Primary Key, Foreign Key constraints
- *Joins*: INNER JOIN, LEFT JOIN, RIGHT JOIN
- *SQL Functions*: Date formatting (TO_DATE), Aggregations, Data conversion
